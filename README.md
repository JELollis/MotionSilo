# MotionSilo

MotionSilo is a local, motion-triggered camera recorder. Video processing and recording happen on the user’s device; no video is uploaded.

## Products

- **Native desktop app** — [desktop/](desktop/): Python and PySide6/Qt Multimedia, with persistent MP4 recordings, playback, and a selectable save folder. The default is `Videos\MotionSilo`.
- **Browser version** — [web/](web/): camera preview, motion-triggered WebM recording, playback, downloads, and optional user-selected folder saving where the browser supports it.

See the README in each directory for launch instructions.
